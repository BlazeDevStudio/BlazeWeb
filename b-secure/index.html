B Secure.

A local password lock for Chrome browsing sessions. Set a password, choose when to relock, and restore parked tabs after unlocking.

Chrome extensionDesktop ChromeLocal data storage
Read privacy policySource on GitHub ↗

What it does

  • Requires a locally configured password to unlock protected browser tabs.
  • Supports configurable failed-attempt limits, cooldowns, and automatic relocking.
  • Restores saved tab URLs after unlocking, with low-memory devices in mind.

Limitations

B Secure is a Chrome extension, not a device or operating-system lock. Anyone who can manage Chrome extensions or the browser profile may be able to bypass or remove it. Unsaved page content may not survive tab parking.

Privacy

Password verification records and saved tab URLs are stored on your device in Chrome extension storage. B Secure does not operate a remote account system or send them to BlazeDevStudio. See the full privacy policy.
